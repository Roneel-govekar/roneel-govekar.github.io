Donation Bazar

A Donation app for donating unused items.

Donation Bazar App

Home Screen

This is the home screen of the Donation Bazar app. The user will long press on the screen to open the login page.

This app also provides way to login using email for leaderboard functionality.

Login Feature

The user can login using their email and password to access the app functionality.

Map Feature

The user can view the leaderboard and track their donation history. Using the map feature the user can explore nearby donation spots.

The map consits of home icon for marking your home location. Home location is not shared with others.

The donation spots are marked with a gift icon. The user can click on the box icon to see the details of the donation item and reason behind donating it. This is where you claim it.

When you want to donate an item, you can place a marker on the map to indicate the location with the reason for donation.

Donating Item

The user can add details of the item they want to donate by clicking on the map. They can provide a reason for donating the item and place it on the map.

The whole point of the app is creating a community of donors and receivers. So the user can also claim an item by clicking on the gift icon on the map and providing a reason for claiming it.

Leaderboard Screen

The user can see the leaderboard and track their donation history.

This is to encourage users to donate more and engage with the community.
